Robustness checks
========================================================================
The amounts used here are in Indian Rupees (INR).
Each run trains the model again and runs all 3 searches, so this takes a
few minutes in all (6 runs here). 28 loans in the data have a negative
residential asset value. They are normally kept as they are.

      47.8%, amount and term 100.0%
  without negative assets (4,241 loans, gradient_boosting)
    accuracy 0.9823  F1 0.9858  ROC-AUC 0.9979

Saved to outputs: robustness_sensitivity.csv, robustness_seeds.csv

How to read this: if the numbers barely move, the results do not depend
on one lucky split or on those few loans. A big move would be a warning.
A high chance of approval is still a model estimate and never a promise
that a lender will approve a loan.

IMPORTANT
------------------------------------------------------------------------
Model-generated what-if result. This is not a lender decision,
a loan offer, or financial advice. A high chance of approval is
an estimate, not a guarantee that a real lender would approve.
Limitations: the model reflects patterns in a public dataset that
lacks economic variables (e.g. inflation, interest rates) and
demographic detail. If no approved option is found, that means none
was found within the searched amounts and terms, not that none exists.
Scores can change with a different data split; run
python -m sharko robustness to see by how much.
